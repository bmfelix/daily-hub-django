How the pieces work

  • One class per page

    Each menu link is a module that owns its page and its API calls. The menu, the homepage, and the URLs are all built from one list.

  • A background listener

    A separate process checks both stations every 15 seconds, updates open pages, saves plays for the charts, and looks up artists and song previews ahead of time.

  • Everything is saved once

    Artists and songs are fetched from MusicBrainz, Wikipedia, Apple, and Deezer one time, then stored, so pages stay fast and those free services are not overused.

  • Tests run offline

    Each outside service sits behind a small client class, so tests swap in a fake and never touch the internet.
